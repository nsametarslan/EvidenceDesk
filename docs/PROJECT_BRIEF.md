# Why this flagship project?

Research date: 7 October 2026. Employer pages were inspected; availability can change.

The recurring work is evidence review and communication, not tool-name accumulation. EvidenceDesk exercises Python, SQL, authentication context, transparent time windows and careful documentation in one small defensive workflow.

| Employer source | Relevant duties | Role-fit constraints |
| --- | --- | --- |
| [PURE7 · Cyber Security Analyst L1](https://www.pure7.com.tr/career/) | Log and alert review, first-level analysis, escalation and incident reports | Bachelor's degree and shift work required; not automatically an eligible application |
| [Soitron · SOC Analist](https://soitron.talentics.app/jobs/733c8e1d-3312-49cd-b85e-4c7c3b6a7269) | Log management, monitoring and technical/customer notification | Engineering graduation and good English required |
| [Diehl · Junior SOC Analyst](https://new.diehl.com/career/de/jobs-bewerbung/stellenboerse/vacancies/junior-soc-analyst-m-w-d) | Initial prioritisation, SIEM/EDR context, documentation and sensor/rule quality | Degree or alternative training/experience; strong German, technical English and on-call expectations |

This is a reasoned design inference from a small sample, not a statistical market survey. No employer affiliation, endorsement or qualification claim is implied. Linux and cloud-specific ingestion can be added only through a tested adapter milestone; they are not bolted on as keywords.

Implementation references: [Flask installation](https://flask.palletsprojects.com/en/stable/installation/), [Flask security considerations](https://flask.palletsprojects.com/en/stable/web-security/). The implementation uses an explicit local threat model rather than assuming framework defaults are sufficient.
